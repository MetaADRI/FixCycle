# Fixcycle PWA monorepo

Installable PWA shell (user app first) backed by the existing Fixcycle Laravel
API. TypeScript strict, npm workspaces.

## Workspace layout

```
pwa/
  apps/
    user/        @fixcycle/user — user app (Next.js App Router + Serwist)
  packages/
    config/      @fixcycle/config — public env + merchant/theme configuration mapping
    api-client/  @fixcycle/api-client — fetch wrapper, envelope parsing, token store, typed errors
    ui/          @fixcycle/ui — design tokens, SVG icon set, layout chrome, primitives
    pwa-core/    @fixcycle/pwa-core — geolocation, install prompt, offline/capability helpers
  scripts/
    generate-icons.mjs  placeholdder PNG icon generator (pure Node, no deps)
```

## Commands

```bash
npm install          # install all workspaces
npm run dev          # dev server for @fixcycle/user
npm run typecheck    # tsc --noEmit across all workspaces with a typecheck script
npm run icons        # regenerate placeholder icons (apps/user/public/icons)
npm run build        # production build of @fixcycle/user
```

## Environment

Copy `.env.example` to `.env` in the monorepo root (`pwa/.env`). Next.js reads
`NEXT_PUBLIC_*` values from the app workspace directory, so also copy it to
`apps/user/.env` until workspace-level env inheritance is configured.

- `NEXT_PUBLIC_API_BASE` — Laravel backend base URL (no trailing slash).
- `NEXT_PUBLIC_MERCHANT_PUBLIC_KEY` / `NEXT_PUBLIC_MERCHANT_SECRET_KEY` — sent
  as `publicKey` / `secretKey` headers on every API request.
- `NEXT_PUBLIC_LOCALE` — default language; `en` is the Phase 1 fallback.

## API contract notes

- Envelope: `version`, `result` (`1` ok / `0` failed / `2` pending / `999`
  unauthenticated), `message`, `data`.
- Configuration endpoint returns app name at `general_config.splash_screen` and
  the merchant accent at `theme_cofig.primary_color_user`; this drives the
  live theme on the splash screen and is shown in `/dev-status`.
- Merchant credentials and a reachable API base must be provided before the
  splash screen can move past its local defaults. Until then `/dev-status`
  reports the failure and the app renders branded defaults.

## Known gaps

  PHP+PostgreSQL environment or a connection string is required.
- Merchant keys, Google Maps key and OneSignal web key values are not
  available; all remain env placeholders.
